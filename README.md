# Учёт учебных заданий

Индивидуальный курсовой проект Трипядько Е. Г.
Python 3, консольный интерфейс, стандартная библиотека.

## Запуск

Распакуйте архив в доступную для записи папку. Требуется Python 3.10 или новее.
Откройте терминал в папке проекта:

```sh
python main.py
python -m unittest -v
python metrics.py
```

В Windows можно использовать `py -3` вместо `python`.
Пункты 1–4 добавляют, показывают, выполняют и удаляют задания; 0 завершает работу.
Файл tasks.json создаётся рядом с main.py; изменения сохраняются сразу.
При отказе записи изменения не принимаются. При повреждении JSON запуск
останавливается: сохраните копию и исправьте файл. Отсутствующий файл означает
пустой список. Номера уникальны среди существующих заданий; после удаления
наибольший номер может использоваться повторно. Одновременный запуск двух
экземпляров не поддерживается.

## Проверки и метрики

В evidence находятся план, протоколы 10 консольных сценариев, 8 unittest,
два запуска демонстрации и исходные данные метрик. Сценарии воспроизведены
подачей заранее заданных строк на стандартный ввод; вывод проверен по ожиданиям.
Это не исследование удобства с независимыми пользователями.

Холстед: анализируются только main.py и task_manager.py по отдельности с
объединением счётчиков. OP и ключевые слова — операторы; NAME, кроме ключевых
слов, NUMBER и STRING — операнды. Разделители, точка и скобки учитываются как OP.
Строки документации, комментарии, отступы и переводы строк исключаются.
Литерал учитывается по исходному написанию, f-строка целиком является операндом
в Python 3.11 (версия анализа записана в metrics.json). Это явно выбранный
лексический вариант, а не единственно возможное определение для Python.
Полные частоты токенов приведены в metrics.json.

Маккейб: база 1; if/elif, for/while, except, условное выражение — по 1;
каждая дополнительная связь and/or — 1; генератор — 1 плюс его фильтры.
else, try, finally и return не добавляют решений. Для complete_task: for + if,
то есть 3. Никакие пороги Холстеда не используются для объявления качества.

История реальных этапов сохранена в coursework.bundle. Для восстановления:

```sh
git clone coursework.bundle coursework-study-tasks
```

Публикация не выполнена: авторизация GitHub отсутствует. Войдите под EgorT351,
